# Stakeholder Assumptions

This document outlines the core assumptions regarding the users of the Disengagement Early-Warning Tool and the ethical boundaries of its use.

## Primary Users
1. **Instructors (Workshop / Practical)**: Use the tool primarily in offline-first, mobile-friendly environments to capture attendance, practical observations (using a competency rubric rather than binary pass/fail), and ad-hoc feedback. They need quick, low-friction entry.
2. **Coordinators / Counselors**: Use the dashboard to review risk flags, resolve sync conflicts, and coordinate interventions. They rely on the transparent scorecard to understand *why* a student is flagged before initiating a conversation.
3. **Admin (Low Connectivity)**: Require text-heavy, low-bandwidth views of the dashboard to ensure the tool is usable in areas with poor internet infrastructure.

## Ethical Boundaries & "What This Is Not"
- **NO Automatic Penalties**: This tool is strictly an *early-warning system*. It must never be used to automatically disqualify a student from exams, deduct grades, or issue punitive actions.
- **NO Public Ranking**: Risk bands are confidential and must never be displayed to peers or used to rank students.
- **NO Black Box Decisions**: The system relies on a transparent, additive point-based scorecard. Staff must be able to see the exact point contributions (e.g., attendance -2, practicals +3) that led to a risk flag.
- **NO Unverifiable Flags**: Flags derived from low data (e.g., a sparse new-entrant) will explicitly state "Low Confidence".
- **Human-in-the-Loop**: The tool suggests risk; humans confirm it. The system provides a mechanism to mark flags as False Positive or False Negative to improve institutional understanding.
